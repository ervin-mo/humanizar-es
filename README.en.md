**humanizar-es** rewrites Spanish text generated by ChatGPT, Claude, Gemini or DeepSeek so
that **Grammarly's AI detector stops flagging it**, without changing what it says and
without adding spelling or punctuation errors. It runs on your own computer with an open
model: no API, no keys, no per-word fees, and your text never leaves your machine. Use it
by hand or as a *skill* for your coding agent (Claude Code, Codex, OpenCode, Antigravity).

| AI-generated essay (Spanish) | Before | **After** |
|---|---|---|
| Tourism and AI in Chiapas · 1,150 words | 77% AI | **0% AI** |
| Dragon Ball and its generation · 910 words | 84% AI | **10% AI** |
| An AI model for classification · 690 words | not measured | **0% AI** |

## How it works

Two ideas, each measured on its own:

```
 your text ─► 1. hip.py ─► 2. you fix 2-3 words ─► 3. unir.py ─► final text
              rewrites with a       (what the model           joins the sentences
              local BASE model       changed too much)         of each paragraph
```

**1. Rewrite with a base model, not a chat model.** Detectors mostly recognize the
*fingerprint of chat training*: everything ChatGPT or Claude writes carries it, even when
you ask it to "sound human". A **base** model, without that training, writes like people
do. Xu et al. (2026) showed this in
[*Base Models Look Human To AI Detectors*](https://arxiv.org/abs/2605.19516): on GPTZero
and Pangram, base-model text scored 97–99% human and its chat version 17–30%. `hip.py`
runs Qwen3-4B-Base with the HIP adapter from that paper.

**2. Break the rhythm.** Grammarly recognizes the rhythm of AI text: sentences of even
length, each with its own period. `unir.py` joins the sentences of each paragraph with
"y" ("and"), the way someone writes in one go, without touching any other word.

Both steps are needed. Same essay, one change at a time:

| Version | Grammarly |
|---|---|
| Rewritten by `hip.py` | 84% |
| … plus double spaces | 84% |
| … removing commas | 60% |
| … joining some sentences with "y" | 40% |
| … **joining every sentence in each paragraph** | **8%** |
| The original, without `hip.py`, joining every sentence | 57% |
| Rewriting with a chat model (several recipes) | 64–100% |

All measurements (in Spanish): [`references/evidencia.md`](references/evidencia.md).

## Install

### With your agent (easiest)

```bash
git clone https://github.com/ervin-mo/humanizar-es.git
cd humanizar-es
python3 install.py          # on Windows: python install.py
```

Open a new session and ask it to **"humaniza este texto"** (humanize this text). The skill
tells the agent what to do: install what is missing (it asks before downloading the
model), list with you what must not be lost, rewrite, show you every change, join and
verify.

| Agent | Skills folder | Covered by `install.py`? |
|---|---|---|
| Claude Code | `~/.claude/skills` | yes |
| Codex | `~/.agents/skills` | yes |
| OpenCode | `~/.agents/skills`, `~/.claude/skills` | yes |
| Antigravity (`agy`) | `~/.agents/skills` | yes |
| DeepSeek Harness (`dsh`) | `~/.agents/skills` | yes |
| Gemini CLI | `~/.gemini/skills` | with `--agente gemini` |

### The model (once, ~4.6 GB)

You need Python 3.9 or newer, with no extra packages, and
[llama.cpp](https://github.com/ggml-org/llama.cpp):

| | macOS and Linux | Windows |
|---|---|---|
| llama.cpp | `brew install llama.cpp` | `winget install llama.cpp` |
| The model | `python3 scripts/instalar_hip.py` | `python scripts\instalar_hip.py` |

The installer checks every file against its sha256 and resumes if the download is cut.
It runs on CPU: 8 GB of free RAM is enough, no GPU. On an M4 Mac it takes about 30 seconds
per paragraph; on a few-years-old PC, 1 to 3 minutes.

## Use it by hand

On Windows type `python` where it says `python3`.

**1. List what must not be lost** in `conceptos.txt`: full proper names, figures, terms.
One per line, variants with `|`, `*` for prefixes.

```text
René Descartes | Descartes
principio de no contradicción
deslave*
```

**2. Rewrite** (paragraph by paragraph; it retries if a paragraph loses a concept):

```bash
python3 scripts/hip.py my-text.txt -o rewritten.txt --conceptos conceptos.txt
```

**3. Review and fix by hand, before joining.** The model sometimes changes a detail,
inverts an idea, gets a gender or a date wrong, or drops an accent:

```bash
python3 scripts/verificar_fidelidad.py my-text.txt rewritten.txt --conceptos conceptos.txt
```

Fix **only the culprit word**. Don't ask ChatGPT to fix it: it puts back the fingerprint
the base model removed.

**4. Join the sentences:**

```bash
python3 scripts/unir.py rewritten.txt -o final.txt --conceptos conceptos.txt
```

**5. Measure** in the detector, together with a text you wrote without AI as a control
([`references/detectores.md`](references/detectores.md)).

A complete example, including what was fixed by hand, is in [`ejemplos/`](ejemplos/).

## FAQ

**Is it free? Do I need an OpenAI key or any account?**
Free and keyless. The model downloads once and runs on your computer; your text never
leaves it.

**Does it change what my text says?**
It shouldn't: `hip.py` retries when a concept is lost, `verificar_fidelidad.py` checks
concepts and negations, and you review every paragraph before joining. In testing, 79 of
80 concepts were preserved.

**Does it add typos on purpose, like other "humanizers"?**
No. Typos also lower the score, but they leave visible errors. This recipe doesn't touch
spelling or punctuation.

**Does it work in English?**
The HIP adapter was trained on English, so the rewriting does; `unir.py` is built for
Spanish ("y", "pero", "además"). Nobody has measured it in English yet.

**Why does the final text have such long sentences?**
That's what makes it pass: Grammarly recognizes sentences of even length. If your text
needs short, polished sentences, this isn't your method.

**Do I need a GPU?**
No. It runs on CPU, at low priority so your computer stays usable.

## Limits

1. **Optimized for Grammarly, with three measured essays.** GPTZero and ZeroGPT are the
   next improvement (see [Detectors](#detectors)).
2. **Paragraphs become long chained sentences.** That's part of how it passes.
3. **Rereading is not optional.** The model was trained on English and sometimes changes a
   detail or inverts an idea; in one essay it flipped the meaning of the conclusion.
4. **Every fix made by a chat model adds points.** Fix little, and by hand.
5. **Detectors change.** This is a snapshot of October 2026.

## Responsible use

Made for text you sign and answer for: brand content, outreach, documentation, emails,
drafts written with AI help. **Don't use it to hand in graded work as your own where AI is
banned or must be disclosed.** That problem isn't technical; it's academic honesty.
